## Creación de usuario

Crear un nuevo usuario:

```bash
useradd nombreDelUsuarioNuevo
```

Dos opciones importantes:

| Opción | Rol |
|--------|------|
| `-d /ruta` | Definir un *directorio home* específico |
| `-m` | Forzar la **creación** del *directorio home* |
| `-s /bin/bash` | Definir el shell de inicio de sesión |
| `-G grupo1,grupo2` | Añadir el usuario a grupos secundarios desde la creación |

```bash
useradd -d /home/test -m usuario
```

> [!TIP]
> En Debian y derivados, `adduser` es un script interactivo construido **sobre** `useradd`: crea el home, copia el contenido de `/etc/skel`, solicita la contraseña e información del usuario.
>
> ```bash
> sudo adduser usuario
> ```
>
> `useradd` sigue siendo la opción correcta en un **script** (no interactivo, comportamiento idéntico en todas partes).

## Listar los grupos de un usuario

Listar mis grupos:

```bash
groups
```

Listar los grupos de otro usuario:

```bash
groups otroUsuario
```

Ver también, con más detalle (UID, GID, todos los grupos):

```bash
id usuario
```

## Modificar un usuario

Añadir un grupo a un usuario:

```bash
usermod -aG nuevoGrupo usuario
```

> [!WARNING]
> El `-a` (*append*) es **obligatorio** con `-G`. Sin él, `usermod -G grupo usuario` **reemplaza** la lista completa de grupos secundarios del usuario y lo retira de todos los demás — incluyendo `sudo`.

Retirar un usuario de un grupo:

```bash
gpasswd -d usuario grupo
```

o, en Debian y derivados:

```bash
deluser usuario grupo
```

Otras modificaciones comunes:

| Comando | Efecto |
|----------|-------|
| `usermod -l nombreNuevo nombreAnterior` | Renombrar el usuario |
| `usermod -s /usr/bin/zsh usuario` | Cambiar su shell |
| `usermod -L usuario` | Bloquear la cuenta |
| `usermod -U usuario` | Desbloquear la cuenta |

> [!IMPORTANT]
> Los cambios de grupo solo se aplican a las **nuevas** sesiones. El usuario debe desconectarse/reconectarse (o ejecutar `newgrp grupo`) para que sus nuevos derechos sean efectivos.

## Eliminar un usuario

```bash
userdel usuario
```

Eliminar también su *directorio home*:

```bash
userdel -r usuario
```

## Listar los usuarios de la máquina

```bash
cat /etc/passwd
```

Cada línea sigue este formato:

```text
usuario:x:1001:1001:Comentario:/home/usuario:/bin/bash
    │    │   │    │       │            │            │
   nombre │  UID  GID    GECOS        home         shell
         └─ contraseña (la "x" remite a /etc/shadow)
```

> [!NOTE]
> Las contraseñas **no** están en `/etc/passwd` (legible por todos) sino en `/etc/shadow`, en forma de hash y legible solo por root.
> Un usuario cuyo shell es `/usr/sbin/nologin` o `/bin/false` es una cuenta de servicio: no puede abrir una sesión.

## Cambiar una contraseña

Cambiar la contraseña del usuario actual:

```bash
passwd
```

Cambiar la contraseña de otro usuario — **como root**:

```bash
passwd usuario
```

Forzar a un usuario a cambiar su contraseña en el próximo inicio de sesión:

```bash
passwd -e usuario
```

## Gestión de grupos

Crear un grupo:

```bash
groupadd nombreDelGrupo
```

Eliminar un grupo:

```bash
groupdel nombreDelGrupo
```

Listar los grupos presentes en la máquina:

```bash
cat /etc/group
```

## Cambiar de usuario

```bash
su - usuario
```

El guión (opcional) activa un **shell de inicio de sesión**: carga el entorno completo del usuario objetivo y coloca la terminal en su *directorio home*.

| Comando | Efecto |
|----------|-------|
| `su usuario`   | Cambia de usuario pero **mantiene** el entorno y el directorio actual |
| `su - usuario` | Abre una sesión propia, como un inicio de sesión real |

> [!TIP]
> La diferencia entre shell de inicio de sesión y shell interactivo determina qué archivos de configuración se cargan (`~/.profile` vs `~/.bashrc`). Este es el tema del [capítulo 10](10_shell_config_es.md).

## El usuario root (admin)

La cuenta `root` es el administrador de la máquina. Todo lo que concierne a la gestión del sistema (añadir un usuario, instalar paquetes, configurar servicios…) debe ejecutarse como root.

> [!CAUTION]
> **Permanece como root el menor tiempo posible.**
> El principio es hacer el máximo de cosas con el mínimo de derechos: un error tipográfico como root puede destruir el sistema, y un shell root abierto es una puerta muy abierta.

Dos métodos posibles:

### 1. Ejecutar *un* comando como root — **fuertemente recomendado**

```bash
sudo comando
```

También puedo especificar el usuario cuya identidad quiero asumir:

```bash
sudo -u usuario comando
```

### 2. Cambiar de usuario — reservado para sesiones de administración

```bash
su
```

```bash
su root
```

```bash
sudo su -
```

> [!NOTE]
> En Ubuntu, la cuenta root no tiene contraseña por defecto: `su` falla, hay que pasar por `sudo`.
> La configuración detallada de quién puede hacer qué a través de `sudo` se trata en el [capítulo 05 · Seguridad](05_securite_es.md#sudosudoers).

### Salir de una sesión

```bash
exit
```

o el atajo `CTRL + D`.

## Resumen

| Comando | Rol |
|----------|------|
| `useradd` / `adduser` | Crear un usuario |
| `userdel -r` | Eliminar un usuario y su home |
| `usermod -aG grupo user` | Añadir a un grupo |
| `gpasswd -d user grupo` | Retirar de un grupo |
| `groupadd` / `groupdel` | Crear / eliminar un grupo |
| `groups` / `id` | Ver los grupos de un usuario |
| `passwd` | Cambiar una contraseña |
| `su -` | Cambiar de usuario |
| `sudo` | Ejecutar un único comando como root |
| `/etc/passwd` · `/etc/group` · `/etc/shadow` | Cuentas · grupos · contraseñas |
